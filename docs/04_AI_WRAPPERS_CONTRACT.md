# AI advisory and Wrappers integration contract
Wrappers upstream: https://github.com/lokah1945/wrappers ; protocol/provider gateway, NOT voting engine. Python orchestrator owned by EA project. Configured exact provider/model IDs only; never silent model substitution. Use only active, authorized providers; resolve coarena scope discrepancy before enabling; do not inspect frozen blackbox/opencode provider implementations.
Transport: MT5 -> authenticated local service, or TLS authenticated service when remote; no public plaintext HTTP. Bounded WebRequest timeout, preferably queue/poll or local IPC bridge to avoid blocking scan. MT5 Strategy Tester uses deterministic replay/mock, not WebRequest.
Request schema v1: schema_version, signal_id, account_scope_hash (not account number), symbol, side, strategy, regime, generated_at_utc, expires_at_utc, bid, ask, spread, ATR, ADX, other normalized features, baseline SL/TP and risk ceiling, risk_policy_version, nonce. Reject missing fields, NaN/Inf, invalid timestamps, duplicate nonce, unsupported schema.
Response schema v1: schema_version, signal_id, decision APPROVE|REJECT|WAIT, risk_multiplier in [0,1], optional bounded SL/TP profile, model_votes with provider/model/version/latency/status, aggregate_reason, decided_at_utc, expires_at_utc, orchestrator_version. Validate exact signal match, symbol/side, timestamp, numeric bounds and policy before any trade.
Model outputs structured and independently validated; consensus thresholds, abstentions and correlated-model disagreement explicit. Model quorum failure/timeout/malformed/expired => REJECT for new AI-gated entries. Log cost, p50/p95/p99 latency and disagreement. Never send secrets, account credentials, or personal data in prompts.
Current Python decision_server.py is deterministic baseline, not Wrappers AI; current MQL5 bridge uses fragile string matching and is informational only. Replace before trading.
