# Risk engine and execution
Hard guards MQL5 only: max per-trade equity risk, max account aggregate risk, daily realized+unrealized loss, peak-to-trough equity drawdown, max simultaneous positions, currency exposure/correlation, per-symbol cooldown, max spread/slippage, min reward/risk, session/news validity, emergency kill switch. Conservative research defaults require explicit configuration and verification; no universal profitable threshold.
Before order: confirm signal TTL, quote freshness, symbol tradability, spread, freeze/stops levels, min/max/step volume, tick value/size, account currency conversion, free margin, netting vs hedging, filling policy, trading permissions and retcodes. Use broker stop-level validation and post-order reconciliation.
Idempotent order intent keyed by signal ID + symbol + strategy; recover from partial fills, requotes, disconnections, terminal restart. Never double-enter from retries. SL/TP and position management remain active without AI; protect against loss of network and broker rejection.
AI risk multiplier cannot exceed 1 or raise EA hard limits. No martingale, grid recovery or uncapped averaging. No live order code enabled until compile, test, demo and explicit user approval.
